**Build and Flash**

This is a PlatformIO project targeting the M5Stack Cardputer’s ESP32-S3 and 8 MB flash, configured as `m5stack_cardputer` in `platformio.ini`. The README’s build and upload targets match that configuration. Node.js is already available in your environment; the `pio` command is not currently recognized.

From PowerShell in the repository root, install the project’s pinned PlatformIO dependency in a virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Build the firmware:

```powershell
.\.venv\Scripts\pio.exe run -e m5stack_cardputer
```

Connect the Cardputer with a USB data cable, then flash it:

```powershell
.\.venv\Scripts\pio.exe run -e m5stack_cardputer -t upload
```

If PlatformIO doesn’t select the right serial port automatically, specify yours (replace `COM5`):

```powershell
.\.venv\Scripts\pio.exe run -e m5stack_cardputer -t upload --upload-port COM5
```

The build hook runs `npm ci` and bundles the web UI automatically; your installed Node.js version meets the project’s requirement. On the first build, PlatformIO will also download the toolchain and libraries. It creates `wled00/my_config.h` from the sample if that file is missing.

The firmware binary is in `.pio/build/m5stack_cardputer/firmware.bin`. The post-build script also copies it to `build_output/release/` with a versioned name. Use PlatformIO’s upload target to flash it, since that handles the board’s flash layout. The README’s prebuilt `WLED-CardPuter.bin` filename doesn’t match the name generated by the current build script.
